# Bank System:
A banking system allows users to manage their accounts by performing basic operations like creating an account, depositing or withdrawing money, checking account balances, and closing accounts. The system will have a menu interface where users can choose various options based on their needs.
## Features:
✅ Create a new customer account.

✅ Login with email and password.

✅ View account details.

✅ Deposit money (50 to 30,000 EGP).

✅ Withdraw money (50 EGP up to your balance).

✅ View transaction history.

✅ Close the account.

## Requirements:
C++ Compiler (e.g., Code::Blocks or Visual Studio) Command Prompt or Terminal to run the program

## How to run

Open `BankManagementSystem.cpp` in Code::Blocks and press Build and Run (F9).
